Apply them to EVERY page without exception.

----------------------------------------------------------

Never overload a page with information.

Never display every available field at once.

Users should never feel confused, tired or overwhelmed.

Every page must be easy to scan within 3-5 seconds.

Group related information together.

Create a clear visual hierarchy.

Primary information must always be immediately visible.

Secondary information should be hidden inside:

• Accordions
• Expandable Panels
• Tabs
• Drawers
• Modals
• Progressive Disclosure
• Hover Cards
• "View More" Sections

Instead of shrinking everything to fit on one screen,
reorganize the layout into multiple clean sections.

Whitespace is not empty space.
Whitespace is part of the design.

Increase spacing whenever a section feels crowded.

Do not try to show every feature simultaneously.

Reduce cognitive load.

If multiple badges exist,
display only the highest priority badge.

Avoid duplicate information.

Avoid repeating labels.

Avoid giant walls of text.

Break long content into digestible sections.

Every screen must naturally guide the user's eyes:

Header
↓

Hero / Page Title
↓

Primary CTA
↓

Main Content
↓

Secondary Content
↓

Related Content
↓

Footer

Every page should answer these questions immediately:

What page am I on?

What is the main action?

What is the most important information?

What should I click next?

If these answers are not obvious,
redesign the layout.

----------------------------------------------------------

PRODUCT PAGES

Do not display every product attribute immediately.

Show only:

• Images
• Name
• Price
• Rating
• Primary CTA
• Short Highlights

Move remaining information into:

Description

Specifications

Shipping

Reviews

FAQs

Related Products

Recently Viewed

----------------------------------------------------------

SHOP PAGES

Filters should never overwhelm users.

Collapse advanced filters.

Group filters by category.

Only expanded filters should be visible.

----------------------------------------------------------

ADMIN PANEL

Never show every filter, every action and every column at once.

Group actions.

Use dropdown menus.

Use bulk action menus.

Hide advanced options until required.

Make dashboards clean and readable.

----------------------------------------------------------

TABLES

Avoid giant tables.

Use:

Search

Sorting

Filters

Pagination

Expandable rows

Details drawer

Sticky headers

----------------------------------------------------------

FORMS

Split long forms into sections.

Use step forms whenever appropriate.

Group similar fields.

Provide helper text.

Reduce scrolling.

----------------------------------------------------------

READABILITY CHECK

Before completing ANY page, verify:

✔ Is the page visually clean?

✔ Is information grouped correctly?

✔ Is there enough whitespace?

✔ Can a new user understand it in under 5 seconds?

✔ Is there unnecessary information visible?

✔ Can some information be moved into accordions, tabs or expandable sections?

✔ Is the page pleasant to read?

If any answer is NO,
redesign the page before considering it complete.

The goal is NOT to display more information.

The goal is to create a calm, elegant, premium, world-class user experience.Every page must pass the "Apple Test".

If the page feels crowded, noisy, cluttered or visually tiring, simplify it before moving forward.

Less but better.

Show only what the user needs at that moment.
