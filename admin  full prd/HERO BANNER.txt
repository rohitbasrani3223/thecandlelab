Business Rules
Only Active banners should appear on the website.
Lower priority numbers display before higher numbers.
Deep links must point to valid internal pages.
Banner images should be optimized for fast loading.
Uploaded images should be automatically compressed without noticeable quality loss.
If a banner image is replaced, remove the old image from storage to avoid unused files.
Every create, update, delete, and status change should be recorded in the audit log.
If no active banners are available, the homepage slider should automatically hide or display a default banner.

Drag & Drop Reordering

Instead of manually changing priority, allow admins to drag banners to rearrange them. The system updates priorities automatically.

Security
Only Super Admin/Admin roles can manage banners.
Validate file type and MIME type before upload.
Reject executable or malicious files.
Store images with randomized filenames.
Serve uploaded images through secure CDN/storage URLs.
