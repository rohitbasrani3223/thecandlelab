Business Rules
Sirf one active popup homepage par ek time par show hona chahiye (highest priority wala).
Agar multiple active popups hain to lowest priority number wala pehle dikhega.
Scheduled popup automatically activate aur expire ho.
"Once Per Session" popup browser session mein sirf ek baar dikhna chahiye.
Popup close karne ke baad frequency rule ke hisaab se dobara hi show ho.
Agar image upload nahi ki gayi hai to popup text-only mode mein render ho.
Popup clicks, views aur conversions analytics mein automatically track hon.
Saare create/update/delete/status changes audit log mein record hon.
